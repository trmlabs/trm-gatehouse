## Upgrade

<Tabs>
  <Tab title="Docker">
    Pull the latest changes, rebuild the image and recreate the container. Data is preserved on the named volume.

    ```bash
    git pull
    make docker
    docker stop agent-vault && docker rm agent-vault
    docker run -it -p 14321:14321 -v agent-vault-data:/data gatehouse:local
    ```
  </Tab>
  <Tab title="From source">
    Pull the latest changes and rebuild.

    ```bash
    cd agent-vault
    git pull
    make build
    sudo mv agent-vault /usr/local/bin/
    ```
  </Tab>
</Tabs>

Database migrations run automatically on server startup. No manual steps required.
