# Contributing to Gatehouse

Report bugs and ideas as [issues](../../issues). Pull requests are not accepted.

This repository is a published copy. The maintainers make changes in a private repository, and they appear here in the next sync commit. If an issue leads to a change, it ships that way.

- **Security problems:** do not open an issue. Report them privately as described in [SECURITY.md](SECURITY.md).
- **Upstream fixes:** a fix that helps every Agent Vault user, not only Gatehouse, may belong in [Infisical/agent-vault](https://github.com/Infisical/agent-vault).
- **Secrets:** never put a real credential, internal endpoint or deployment detail in an issue. Use `example.com` placeholders.

This project follows the [Contributor Covenant](CODE_OF_CONDUCT.md). The repository is licensed under the [MIT license](LICENSE).
